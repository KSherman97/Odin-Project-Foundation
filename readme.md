# Odin Project Foundations Course Monorepo

This repo contains the projects from the **foundations** course of [The Odin Project](https://www.theodinproject.com/).
Each project is is organized into its own folder and is self-contained with unique code and assets.

Each project includes a link to view on GitHub Pages. Please note that for most of these projects, the project was completed following specifications, so when UI or other factors don't look polished that is a result of the primary focus being on other aspects of development. Every project was completed using a mix of vanilla HTML, CSS, and JavaScript. No AI was used in the completion of this course, however Google search and a combination of official documentation were used.

---

## Projects
- `Recipes` - Basic HTML and CSS styling [view live](https://ksherman97.github.io/Odin-Project-Foundation/odin-recipes/)
- `Landing Page` - Slightly more complex CSS [view live](https://ksherman97.github.io/Odin-Project-Foundation/odin-landing-page/)
- `Rock-Paper-Scissors` - Simple game implementation in JS [view live](https://ksherman97.github.io/Odin-Project-Foundation/odin-rock-paper-scissors/)
- `Etch-A-Sketch` - Interactive drawing board in JS [view live](https://ksherman97.github.io/Odin-Project-Foundation/odin-etch-a-sketch/)
- `Calculator` - Fully functional calculator with working history display. Complex JS implementation [view live](https://ksherman97.github.io/Odin-Project-Foundation/odin-calculator/)
